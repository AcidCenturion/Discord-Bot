Sophia bot is a fun bot for chat commands in discord modeled after the Persona 5 Scramble Sophia character. 

Sophia Commands:
  _8ball    Ask the 8 ball a yes or no question. 8 ball never lies.
  attack    Need to teach someone a lesson?
  boop      Bother someone kindly.
  bye       Goodbye.
  calculate Can calculate simple 2 number equations. Fractions not supported ...
  clear     Clean up some messages. Requires Manage Messages permission.
  flip      Flip a coin.
  floof     Floof Sophie!
  headpat   Who needs some love.
  hello     Hello.
  help      Shows this message
  highfive  Highfive... or a baton pass.
  horni     BONK!
  hug       Everyone deserves a hug.
  number    Random number generator.
  ping      Check Sophia's connection.
  rps       Play Rock-Paper-Scissors with Sophia.
  salute    Send someone off the proper way.
  sleep     Send someone to bed when they're being rebellious.
  timer     Timer (limit 20s)... until self destruction.
